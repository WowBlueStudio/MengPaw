## 这个文件是什么

`memory/memory.md` 是你的**长期记忆**。它会被注入你的系统提示词——**每次对话你都能看到它**。所以它只放跨会话仍然有效的重要知识，宁缺毋滥。

你的记忆分三轨，都在 `memory/` 目录：

| 轨道 | 文件 | 特点 |
|------|------|------|
| **长期** | `memory.md`（本文件） | 注入提示词、每次可见；只放沉淀后的重要知识 |
| **中期** | `memory_{日期}.md` | 按日期分片、不注入提示词；临时/过程性信息在这，梦境模式会提炼 |
| **项目** | `project_{名称}_memory.md` | 按项目分片，放可复用的项目经验 |

## 这里记什么

跨会话有效的知识，比如：

- 用户的关键偏好和习惯
- 你踩过的坑和教训（确认不再踩后，沉淀到这里）
- 长期有效的环境配置（端口、设备、账号别名、常用路径）
- 反复出现的任务模式（用户经常要什么、你摸索出的最佳做法）

## 示例

```markdown
### 用户偏好
- 提到"文档"指 MengPaw-Development-Guide.md
- 发布前必须先跑 kernel 测试

### 教训
- 305 字段 data class 触发 ART VerifyError 闪退 → 用普通 class + apply
```

## 怎么写入（用命令，别直接编辑文件）

- `agent.memory.keep <内容>` — **写入长期记忆**（本文件）；重要知识直接沉淀
- `agent.memory.record <内容>` — 写入**中期记忆**（按日分片）；临时信息、对话摘要、过程进度
- `agent.memory` — 看长期记忆；`agent.memory.mid` — 看中期；`agent.memory.project` — 看项目
- 直接编辑文件不会触发缓存失效，Agent 看到的可能是旧内容

## 不记什么

- **会话细节、临时进度** → 中期记忆（`agent.memory.record`），梦境会自动提炼
- **每轮都会变的动态信息** → 别进这里（提示词膨胀 + 前缀缓存失效）
- **agents.md 里已有的命令用法** → 别重复
- **记忆孪生会同步这个目录**，写进去的东西也会同步到其他设备，注意分寸
