# 无障碍指南

无障碍（Accessibility）服务让应用可以读取屏幕内容并模拟操作，是"自动化操控设备"类能力的基础。MengPaw 未来将接入无障碍服务实现屏幕级自动操作（当前版本暂未使用，此指南说明概念与开启方式）。

## 开启方式

1. 系统「设置」→「无障碍 / 辅助功能」
2. 找到目标应用（如 MengPaw）
3. 打开服务开关并确认授权

## 用途与边界

- **读取屏幕**：获取当前界面文本与控件结构，辅助 Agent 理解页面状态
- **模拟操作**：点击、滑动、输入，实现跨应用自动化（如自动填写表单）
- **注意**：无障碍权限可以读取密码框外的所有屏幕内容，属于敏感权限；仅在信任场景使用

## 与 MengPaw 的关系

- 当前 Shell 依赖的命令级能力（sys.* / fs.* / net.* 等）不需要无障碍权限
- 若未来启用屏幕级操控，Agent 会在此指南基础上增加对应命令与安全分级
- 第三方无障碍工具（如自动点击器）与 MengPaw 互不冲突
