# 无障碍指南

无障碍（Accessibility）服务让应用可以读取屏幕内容并模拟操作，是"自动化操控设备"类能力的基础。MengPaw 已接入无障碍服务（v0.42.2），Agent 可通过 `sys.accessibility.*` 命令实现屏幕级自动操作。

## 开启方式

1. 系统「设置」→「无障碍 / 辅助功能」
2. 找到目标应用（如 MengPaw）
3. 打开服务开关并确认授权

## 用途与边界

- **读取屏幕**：获取当前界面文本与控件结构，辅助 Agent 理解页面状态（`sys.accessibility.dump`）
- **模拟操作**：点击、滑动、输入、返回/桌面/最近任务，实现跨应用自动化（如自动填写表单）
- **注意**：无障碍权限可以读取密码框外的所有屏幕内容，属于敏感权限；仅在信任场景使用

## 与 MengPaw 的关系

- **开启方式**：设置 → 无障碍 / 辅助功能 → MengPaw → 打开服务开关并确认；随后用 `sys.accessibility.status` 确认
- **命令面**：`sys.accessibility.dump`（读屏，中危）| `click` / `swipe` / `input` / `back` / `home` / `recents`（模拟操作，高危，弹窗确认）
- **安全分级**：模拟操作等同用户亲自点击，全部为 HIGH 风险，Agent 每次执行都需弹窗确认；读屏为 MID
- **与命令级能力并存**：Shell 依赖的命令级能力（sys.* / fs.* / net.* 等）不需要无障碍权限
- 第三方无障碍工具（如自动点击器）与 MengPaw 互不冲突
